## ⭐ Major projects (latest / highest-impact)

### 🔄 [Sync Bridge Monorepo](https://github.com/gedeoni/sync-bridge)
A production-grade, multi-backend database synchronization system demonstrating cross-language architectural parity, high performance, and robust testing standards.
- **What**: Houses 8 independent synchronization services collaborating to handle live database transfers, migrations, and schema mappings.
- **Stack**: Java Spring Boot, NestJS, Express, Django, Rust Axum, Go Fiber, FastAPI, and C# (.NET Core).
- **Core Features**: Centralized Git pre-commit hooks for directory-sensitive automated checks, and an optimized, directory-sensitive GitHub Actions CI pipeline running tests only on modified sub-projects.
- **Repo**: [github.com/gedeoni/sync-bridge](https://github.com/gedeoni/sync-bridge)

### 🤖 [UI/UX Feedback Agent Team (UI Analyser)](https://github.com/gedeoni/ui_analyser)
A sophisticated multi-agent system that analyzes landing page designs, provides expert UI/UX critiques, and automatically drafts improved mockups.
- **What**: Built on LangGraph, LiteLLM, and Pydantic with a Streamlit front-end.
- **Stack**: Python, LangGraph, Playwright, SQLite checkpointing, Ollama (local model execution) & Cloud LLM APIs (Gemini, OpenAI, Anthropic).
- **Core Features**: Website URL crawling via Playwright, direct wireframe image uploads, hybrid text/vision LLM routing, and image minimization pipeline.
- **Repo**: [github.com/gedeoni/ui_analyser](https://github.com/gedeoni/ui_analyser)

### 🧠 [Aura Farm RAG Reasoning Agent](https://github.com/gedeoni/local_rag_agent)
A state-of-the-art, privacy-focused Retrieval-Augmented Generation (RAG) system with long-term memory.
- **What**: A Streamlit chat agent with deep reasoning and real-time structured thinking streams.
- **Stack**: Python, Agno, LanceDB, Model Context Protocol (MCP), DSPy.
- **Core Features**: **MemPalace** semantic memory integrated as an MCP server, LanceDB vector search with self-healing handle recovery, DuckDuckGo anti-block search fallback, and DSPy query optimization.
- **Repo**: [github.com/gedeoni/local_rag_agent](https://github.com/gedeoni/local_rag_agent)

### 📊 [data-pipeline-odoo](https://github.com/gedeoni/data-pipeline-odoo)
- **What**: Automated ETL pipeline integrating Odoo ERP data into an analytics/data warehouse.
- **Stack**: Python-based ETL, data validation, and connectors to Odoo and relational stores.
- **Role**: Designed extraction, transformation, and load flows, securing reliable scheduling and failure retries.
- **Repo**: [github.com/gedeoni/data-pipeline-odoo](https://github.com/gedeoni/data-pipeline-odoo)
